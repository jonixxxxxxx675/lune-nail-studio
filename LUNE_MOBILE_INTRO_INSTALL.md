# LUNE — Mobile Intro

This package updates only the mobile intro (max-width: 767px). Desktop styles and the existing desktop page are left untouched.

## Install
1. Copy/replace `index.html`, `styles.css`, and `intro.js` in the project.
2. Copy the `assets/intro/` folder into the project root.
3. Deploy as usual.

The intro runs once per browser session via `sessionStorage`. It supports reduced-motion and unlocks scrolling on exit/skip.
